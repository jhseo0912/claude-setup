# wrap: 세션은 결과물과 지식만 남긴다

세션이 끝나면 대화 맥락은 사라진다. 남는 건 리포뿐이다.
다음 세션이 30초 안에 이어받을 수 있는 상태를 만들고 닫는다.

## 절차

1. **재고.** `git status`로 변경된 파일과 새 파일을 훑고 세 갈래로 나눈다
   - 결과물: 리포에 남을 코드와 문서
   - 지식: 이 세션에서 확정된 제약, 결정, 상태 변화. 파일이 아니라 사실
   - 부산물: 세션 로그, 작업 지시서, 실험 스크립트, 임시 파일
2. **지식 반영.** distill 스킬의 4갈래(제약/ADR/상태/docs)대로 해당 문서에 기록한다.
   기록 전에 같은 사실이 이미 있는지 grep, 원본은 한 곳.
   미완 작업은 상태 문서에 한 줄로 남긴다. 다음 세션의 시작점이다
3. **부산물 정리.** 지식을 옮긴 부산물은 지운다. git 히스토리가 보존한다.
   이 세션이 만들지 않은 untracked 파일은 목록으로 보고하고 그대로 둔다
4. **검증.** 리포에 테스트나 린트가 있으면 돌린다. 빨간 항목은 고치고,
   이 세션 범위 밖 원인이면 상태 문서에 적고 보고에 포함한다
5. **커밋.** commit 스킬로 메시지를 만들어 커밋하고 푸시한다
6. **보고.** 세 줄로: 옮긴 지식 n건(행선지), 지운 것 n건, 커밋 해시와 검증 상태
