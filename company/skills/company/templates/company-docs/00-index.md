# company-docs

회사 운영에 관한 문서는 전부 여기입니다. 작업 내용은 docs/에 있습니다.
일반 규칙의 원본은 역할 스킬(/role-<역할>)과 claude-setup의 company 템플릿입니다. 여기에는 이 프로젝트 고유의 조직도, 소유 경로, 명부, 기록만 둡니다.

- [org.md](org.md) 조직도, 직급별 허용범위, 운영 규칙, 태스크 규칙, git 규칙, 온보딩. 그룹장이 유지
- [session-protocol.md](session-protocol.md) 세션간 통신 도구, 주소 규약, 카드 형식. HR이 유지
- [roster.md](roster.md) 세션 주소록. 덮어쓰기. HR이 유지
- [roles/](roles/README.md) 팀별 프로젝트 직무와 방법서. 일반 직무는 역할 스킬에 있다
- [decisions/](decisions/) 조직 관련 ADR
- [meeting-logs/](meeting-logs/README.md) 정기보고회의 기록과 주간 마무리. 그룹장이 쓴다
