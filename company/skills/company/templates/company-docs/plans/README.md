# plans/

방향 결정을 시킬 때 쓰는 계획서 자리입니다. 파일 하나에 결정 하나, 40줄 안입니다.
방향 결정과 실행 결정의 경계는 org.md 운영 규칙 11에 있습니다.

## 일곱 칸
| 칸 | 담는 것 |
|---|---|
| 왜 지금 | 숫자와 출처. 없으면 "못 정함" |
| 목표와 범위 밖 | 무엇을 하고 무엇을 안 하는지 |
| 경로와 주인 | 건드릴 경로, 그 일의 주인 역할 |
| 완료 기준 | 검사 행 id나 규칙 문서 포인터만 |
| 대안 하나 | 고르지 않은 길과 그 이유 |
| 실패 신호와 되돌리기 | 무엇이 보이면 접는지, 어떻게 되돌리는지 |
| 받는 쪽이 정할 것 | 방법과 값은 비워 둡니다 |

## 예시 둘
완료 기준 옆에 "이만하면 됨"과 "이건 과함"을 일의 모양으로 적습니다. 카드 수나 시간은 기준이 아닙니다.
받는 쪽 역할 파일의 일하는 방식 보정 절을 읽고 그 사람에 맞춰 예시를 고릅니다.

## 수명
결정이 ADR이나 규칙으로 옮겨지면 지웁니다. 커밋 창 없이 커밋하는 문서 예외입니다.
