# ADR 0001 서브에이전트 대신 세션으로 조직을 만든다

## 결정
그룹장, HR, PM, 팀장, 팀원을 각각 독립 세션으로 둡니다. 교신은 세션 메시지의 카드 형식으로만 합니다. 커밋은 PM만 합니다. 세션 안에서 읽기, 검색, 확인 실행은 Haiku 서브에이전트에 맡깁니다.

## 맥락
서브에이전트는 끝나야 보고하고 중간에 못 묻고 컨텍스트가 호출마다 사라집니다. 세션은 역할과 맥락이 유지되고 중간 질문이 됩니다. 대신 여러 세션이 같은 폴더를 동시에 만집니다.

## 이유
- 팀장이 일을 이어서 맡으려면 맥락이 살아 있어야 합니다
- 모호할 때 시작 전에 묻는 규칙은 세션이라야 됩니다
- 커밋 주체를 하나로 두면 index lock 충돌이 없습니다
- 판단 없는 읽기와 확인은 서브에이전트가 싸고 충분합니다

## 대가
- 세션 생성과 온보딩을 대표가 손으로 합니다
- 보고 규율은 기계가 아니라 사람이 지킵니다. 어기면 HR이 교정합니다
- 경로 소유 규칙을 어기면 파일이 덮어씌워집니다

## 재검토 조건
- 세션이 12개를 넘어 대표의 온보딩 부담이 커질 때
- 같은 파일을 두 세션이 고치는 사고가 두 번 이상 날 때
