# 세션 명부

세션명과 주소입니다. 카드 주소 칸에는 짧은 id(ListAgents 대괄호 값)를 씁니다. 긴 id는 세션 관리 도구의 sessionId입니다. 둘 다 재시작하면 바뀔 수 있어 발송 전 ListAgents로 재확인합니다.
HR이 유지하는 덮어쓰기 문서입니다. 표에 없는 세션은 <프로젝트> 소속 미확인이라 전파 대상에서 뺍니다.

| 역할 | 세션명 | 짧은 id | 긴 id | 상태 |
|---|---|---|---|---|
| 그룹장 | <프로젝트> 그룹장 | | | |
| HR | <프로젝트> HR | | | |
| PM | <프로젝트> PM | | | |
| 비서 | <프로젝트> 비서 | | | |
